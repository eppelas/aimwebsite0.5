# Product Card System

Seed focused element prototype for the AIM Homepage Design Lab.

## Sources Used

- Content/source facts and links: `https://aimindset.org/`
- Design/review patterns: AIM Site Hub, current compare pages, Blocks Lab.

## Intent

Explore a readable card system for homepage ecosystem/product blocks. Cards show destination, status, format, and short source-backed copy without turning the homepage into a flat link list.

## Source Fidelity Notes

- Preserved public product labels and destination categories from the old site: Main Lab, Health/Selfdev sprint references, Space, Team Track, For Non-Profit.
- Some summary lines are compressed for card fit. Production transfer must verify exact current labels and URLs from `aimindset.org`.

## Not Copied

- The cards borrow the operational clarity of the Site Hub and the compare pages, but are not copied from any existing block component.
