# Variable Type Axis Lab

Focused AIM homepage element exploration for typography as an active brand mechanic, not just a readable fallback.

## Sources

- `aimindset.org` source phrases already used in the homepage brief:
  - `Контекст важнее промптов`
  - `мы не “учим пользоваться AI”…`
  - `AI как экзоскелет`
  - `создавать, а не потреблять`
- Current V3 site code uses mono-heavy UI/text accents (`font-mono`) across payment, reviews, and Lab W26 surfaces.
- Google Fonts variable candidates:
  - `Martian Mono` for width/weight-driven technical display.
  - `Roboto Flex` for readable variable body optical sizing.
  - `JetBrains Mono` as a mono fallback/reference layer.

## Idea

This is not a finished homepage block. It is a typography mechanic lab:

- headline axes react to cursor movement;
- manual controls expose `wght`, `wdth`, and `opsz`;
- glyph strip stress-tests Cyrillic/Latin/arrow shapes;
- CTA remains Russian and visually primary;
- real AIM logo asset is used instead of a generic text-square mark.

## Borrowed Formally

- Uses Google Fonts variable axes as implementation material.
- Uses current AIM mono/technical character as direction.
- Keeps mouse-reactive behavior from the better constellation/payment explorations, but applies it to type.

## Not Copied

- No external brand typography, layout, copy, or imagery copied.
- No fake proof, no new product claims, no new testimonials.

## Feedback Response

User rated the previous Signal Field homepage `4/10`: constellation background and some typography were the only promising parts, but the overall page was boring and typography felt too standard/self-serif. This lab responds by making type itself the experimental surface.

## Validation Notes

- Review-only static HTML.
- Uses online Google Fonts imports, so visual fidelity depends on network availability; fallback still works with system monospace/sans.
- Must be judged as a mechanics exploration before porting into a full homepage.
