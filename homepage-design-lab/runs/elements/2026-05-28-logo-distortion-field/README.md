# Logo Distortion Field

Review-only AIM logo motion element. This is not a homepage and not production code.

## Source

- Motion reference: `/Users/viola/Downloads/Asymmetric Motion Recording (1).mp4`
- Brand constraint from user feedback: AIM logo is not locked to white-on-black. It can be black on transparent, white on transparent, inverse split, or a disturbed black field.

## What This Tests

- Asymmetric moving field around the AIM logo instead of a plain black rectangle.
- Pointer-reactive distortion: hover position and pointer velocity affect the wave.
- Controls for intensity, split position, field scale, motion style, and logo mode.
- PNG frame export for later reuse in page reviews.
