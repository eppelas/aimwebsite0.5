# Dynamic Typography Stage

Replacement reference-driven full-homepage prototype for the AIM Homepage Design Lab.

## Why This Replaces The Previous Pass

The first `Dynamic Typography Score` pass looked unfinished: the wordmark broke awkwardly, the composition felt like a wireframe plus a CSS trick, and the typographic behavior was not integrated into a complete page system.

This version keeps the same reference direction but rebuilds it as a finished visual direction: the hero is a typographic stage, the right rail is a 13-block score, and the sections below use the same rhythm without pretending to be production content.

## What Was Borrowed Formally

- Dynamic typography as behavior, not decoration.
- Text as a rhythmic score/frame.
- Classical serif character shapes with contemporary responsive motion.
- A strict black/white base with controlled contemporary color accents.
