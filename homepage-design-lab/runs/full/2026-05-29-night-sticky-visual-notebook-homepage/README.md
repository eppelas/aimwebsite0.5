# AIM Homepage — Sticky Visual Notebook (2026-05-29)

Lane: `homepage / full`

## Idea

A two-column homepage:

- Right column is a calm, readable “notebook” of chapters (the 13-block brief, compressed).
- Left column is a sticky visual stage that updates per chapter (scrollytelling without putting lines/grids behind paragraphs).

## Mechanics

1. **Sticky visual stage** updates image/video + caption based on the visible chapter.
2. **Typography split**: headings in serif, body in proportional sans; monospace only for metadata/tags.
