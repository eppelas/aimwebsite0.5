## Intent

Test whether AIM homepage can use type as an active system: large letterforms subtly stretch, compress, and pulse as a metaphor for living context and AI-augmented thinking.

## What Was Borrowed Formally

- Responsive/variable-style letter behavior.
- Text as a framing and rhythm device.
- Contrast between formal typographic restraint and contemporary motion.
